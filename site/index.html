takeback

The undo button for agents.

Consequential actions wait in a grace window. Undo cancels them before they ever run.

GitHub
❯ npm install takeback

How it works

Most undo tries to reverse an effect that already happened. takeback defers the effect instead: onCommit fires only when the grace window closes, so an undo is not a rollback. It is a veto.

proposed

High severity waits here for a human to confirm.

reject ↳ nothing ran

pending

The countdown runs. The action is visible and inert.

undo ↳ nothing ran

committed

The effect runs exactly once, after the window.

Usage

Headless core, thin React layer. The engine has zero dependencies and works without React.

import { ReversibleProvider, UndoToast, useReversible } from "takeback";

const { propose } = useReversible();

propose({
  intent: "send-email",
  description: "Send follow-up to 3 clients",
  severity: "medium",               // "high" gets a confirm gate
  onCommit: async () => api.send(),  // runs only if nobody hits Undo
});
