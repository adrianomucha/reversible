The undo button for agents.

takeback puts a preview and undo layer around any consequential AI action. Nothing runs until a grace window closes. Undo is free, because the effect never happened.

How it works

Defer the irreversible.

Most undo tries to reverse an effect that already happened. takeback holds the effect back instead. During the window nothing has run, so undo just cancels a pending intention. It is Undo Send, generalized to any agent action.

01

Propose

The agent declares what it wants to do: an intent, a description, a diff. High severity actions wait behind a confirm gate until a human approves.

02

Grace window

Approved actions sit in a pending state with a visible countdown. Undo cancels the intention outright. There is nothing to roll back.

03

Commit

The real effect runs exactly once, when the window closes. Never on propose. Never on optimistic apply. Async errors stay contained.

proposed ──confirm──▶ pending ──(grace elapses)──▶ committed
   │                    │
 reject                undo
   ▼                    ▼
rejected             undone                onCommit fires only on pending → committed

Two lines of integration

Headless core. Thin React layer.

The engine has zero dependencies and zero React imports. Use it from Node, vanilla JS, or any framework. The React bindings add a provider, hooks, and drop-in components.

React
import { ReversibleProvider, UndoToast, useReversible } from "takeback";

const { propose } = useReversible();

propose({
  intent: "send-email",
  description: "Send follow-up to 3 clients",
  severity: "medium",  // 8s undo window
  onCommit: async () => {
    await api.sendEmails(); // runs only if
  },                        // nobody hits Undo
});
Headless, no React
import { ReversibleEngine } from "takeback/core";

const engine = new ReversibleEngine({ defaultGrace: 8000 });

const { controls } = engine.propose({
  intent: "delete-files",
  description: "Delete 12 stale build files",
  severity: "high",  // waits for confirm
  onCommit: () => api.deleteFiles(),
});

controls.undo(); // the effect never runs

Built for production

Small surface. Sharp edges filed down.

Headless first

A framework-agnostic state machine at the core. React is an optional peer dependency, not a requirement.

Zero dependencies

The core ships nothing but itself. About 9 kB of ESM with full TypeScript types, strict mode throughout.

Severity aware

Low and medium actions run optimistically with an undo window. High severity waits behind a confirm gate.

Accessible

Focus-trapped alert dialog, Esc to cancel, polite live regions, and full prefers-reduced-motion support.

Deterministic

The clock is injected. Tests drive time with advance() and run in milliseconds with no real timers.

Composable UI

UndoToast, PreviewDialog, CountdownRing, and ActionDiff read engine state and stay dumb. Styling is opt-in.
